# Изменения

## 3.1.0 — в разработке

- Роль использует установленный клиент `mc`/`mcli` и настроенный alias; доступ проверяется через `admin info`.
- Действия выбираются тегами: применение, экспорт, dry/dryrun и очистка. Штатный `--check` Ansible работает независимо от выбора действия.
- Настраиваются бакеты, versioning, анонимный доступ, пользователи, группы и их членство.
- IAM-права задаются в `statements`; для каждого правила создаётся отдельная политика владельца с уникальным внутри него `Sid`.
- Перед изменением политик проверяется исключительное владение их прямыми назначениями.
- Экспорт содержит три списка: `minio_configuration_users`, `minio_configuration_groups`, `minio_configuration_backets`.
- В YAML-выгрузке сохраняется читаемый порядок полей; списки Action/NotAction и Resource/NotResource записываются в одну строку.
- Удаление лишних объектов контролируется флагами; защищённые пользователи исключаются из удаления.
- Перед задачами, включая вложенные блоки и тестовые playbook, используются пустые строки.
- Предусмотрены локальные тесты и Molecule-сценарий для Docker-кластера MinIO.
