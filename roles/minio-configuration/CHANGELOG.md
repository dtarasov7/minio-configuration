# Изменения

## 1.0.0 — 2026-10-08

- Добавлены стандартные режимы и явные IAM-политики анонимного доступа.
- Добавлены несколько IAM Statement и именованных политик для пользователя,
  явные запреты, маски бакетов и объектов, условия доступа.
- Пользователи обновляются без удаления; пароль можно опустить для существующего пользователя.
- Добавлен экспорт inventory YAML с бакетами, политиками, пользователями и группами.
- Удалена поддержка переменных без префикса `minio_configuration_`.
- Добавлены локальные проверки и сценарии Molecule для прав доступа и экспорта.

- Defaults переведены на явные IAM Statement без изменения стандартных разрешений.
- Членство пользователя задаётся полем groups и синхронизируется во всех текущих группах;
  отсутствие поля снимает всё членство. Группы создаются по назначенным пользователям.
- Alias mc задаётся переменной minio_configuration_alias и сохраняется в экспорте.
- В README добавлены 59 имён S3 Action релиза 2025-10-15 и s3:*, ограничения API,
  примеры NotResource и явных исключений Deny.

- Удалена сокращённая форма пользовательских разрешений; права задаются IAM Statement.
- Группы поддерживают statements прямо в описании, как пользователи.
- Сгенерированные политики разделены по сущностям: minio-configuration-user-<имя>
  и minio-configuration-group-<имя>. Одинаковые прямые права разных пользователей
  создают отдельные политики; права группы наследуются всеми её участниками.

- Каждое правило пользователя и группы создаёт отдельную политику с именем владельца,
  Sid и типом user/grp. Совместное назначение создаваемых ролью политик запрещено.
- Sid обязателен и уникален внутри одного владельца; у разных владельцев может совпадать.
- Перед изменением документов проверяются прямые назначения всем внутренним пользователям
  и группам, включая созданных вне роли; чужое назначение блокирует изменение.
- Удалены общие списки политик. Экспорт разворачивает текущие политики в statements
  владельцев и формирует устойчивые Sid для отсутствующих/повторяющихся идентификаторов.
